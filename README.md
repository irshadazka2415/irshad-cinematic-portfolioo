# IRSHAD — Cinematic Portfolio

A one-page, dark editorial portfolio inspired by the uploaded reference Reel. It uses Next.js App Router and plain CSS for the animation layer, so there is no animation library dependency to maintain.

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Import the project into Vercel. The current Next.js docs recommend the App Router for new projects; Node.js 20.9+ is supported by the current setup.

## Personalisation

Edit `app/page.tsx` for your content. Replace the `portraitPlaceholder` with a real photo later if desired. Update the GitHub and email links before publishing.
